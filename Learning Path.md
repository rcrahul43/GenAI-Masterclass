## Track D — Primary course (default)

**Persona:** Learn GenAI from scratch; stay relevant ~10 years as India expands AI + data centers.

| Resource | Role |
|----------|------|
| **[COURSE.md](COURSE.md)** | Entire course design |
| **[Study Plan](Study%20Plan.md)** | 48-week / 6-block execution |
| **[India AI Career Learning Plan](Career/India-AI-Career-Learning-Plan.md)** | Market context + monthly narrative |

### Sequence

| Months | Block | Outcome |
|--------|-------|---------|
| 1–2 | Foundations | Hello-LLM + FastAPI |
| 3–4 | LLM apps | Document helper |
| 5–6 | Agents + RAG | Support agent + FAQ bot |
| 7–8 | Quality | Evals + guardrails |
| 9–10 | Deploy/cost | Docker + ₹/query |
| 11–12 | Specialize + jobs | Flagship + applications |

### Year-1 roles

GenAI / LLM Application Engineer · RAG / AI Solutions Engineer · (optional) junior inference-curious platform engineer

## Track A — Staff / Principal AI Engineer (IC)

**When:** After Track D portfolio **or** you already ship LLM systems.

Follow [Master Study Roadmap](Master%20Study%20Roadmap.md) Phases 0–11 at full depth (~30 weeks at 12–15 h/week).

**Success:** 12+ production-style apps · RAG platform · eval CI · 8 system designs · Staff mock ≥4/5.

---

## Track B — Engineering Manager (AI / Platform)

Same phases as A with lighter GPU/FT labs; heavy Phase 11 + [12-06](Modules/12-Advanced-Topics/12-06-AI-Product-Thinking.md) + `Leadership/` + [EM Interview Guide](Career/EM-Interview-Guide.md).

---

## Track C — Hybrid Tech Lead → EM

Alternate Tech Deep days (Track A labs) and Leadership days. Add ≥2 h/week from `Leadership/` and EM guide.
